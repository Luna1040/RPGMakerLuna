# B-04｜独立战役导入与隔离安装实施说明

## 导入流程

```text
published-content/1
→ campaign-import-request/1
→ Main Agent 调用 preview_campaign_import
→ 校验发布制品 Schema 与 artifact_hash
→ 在当前可信基础目录上重新物化完整候选内容
→ 复核 candidate_content_hash、严格字段、任务图、奖励、NPC 资产和交叉引用
→ 返回 campaign preview_token、安装目录和独立存档命名空间
→ Main Agent 调用 install_campaign
→ 临时目录落盘并回读校验
→ 原子重命名为正式战役包
```

Main Agent 必须显式执行预览和安装两个动作。安装令牌与请求、来源制品、内容哈希、manifest 哈希以及当前目录上下文绑定；任一内容或基础 revision 变化都要求重新预览。

## 新增合同

- `content/schemas/campaign-import-request.schema.json`
- `content/schemas/campaign-content.schema.json`
- `content/schemas/campaign-manifest.schema.json`

导入请求固定包含：

- `request_id`
- `project_id`
- `draft_id`
- 新的 `campaign_id`
- 显示名称
- `activation_policy`

支持的激活策略：

- `new_campaign`
- `explicit_project_copy`

`campaign.official.*`、`campaign.base.*` 和 `campaign.system.*` 是保留 ID。项目、草稿和战役 ID 必须符合规范化格式，Agent 不能提交任意文件路径。

## 独立战役包

安装结构：

```text
user://projects/<project_id>/campaigns/<campaign_id>/
├── manifest.json
└── content.json
```

`content.json` 冻结：

- 完整技能目录
- 完整装备目录
- 完整 NPC 目录
- 完整任务、对话、商店、配方与剧情图目录
- 来源 catalog hash 与 revision
- 发布制品的候选内容哈希
- 战役内容校验和

`manifest.json` 记录：

- 项目与战役身份
- 显示名称和激活策略
- 来源草稿与制品哈希
- 来源目录上下文
- `content.json` 的校验和
- 固定相对存档目录 `saves`
- `runtime_activation: "new_session_only"`
- manifest 自身校验和

战役的未来存档目录固定为：

```text
user://projects/<project_id>/campaigns/<campaign_id>/saves
```

它与当前官方 `user://rpg_saves` 完全分离。

## 原子性与不可覆盖规则

安装时先创建唯一同级临时目录，写入 `content.json` 与 `manifest.json`，随后重新读取并执行完整验证。只有两个文件都通过后，才把整个临时目录原子重命名为正式战役目录。

- 相同 `campaign_id`、相同 manifest 重复安装为幂等成功。
- 相同 `campaign_id`、不同内容会被拒绝。
- 已存在但损坏的战役目录会被拒绝，不会自动修复或覆盖。
- 安装期间目标 ID 被其他操作占用时会停止，并清理自己的临时目录。
- 单文件最大 8 MiB；超过限制不会进入安装目录。

## 二次可信校验

导入器不会把发布制品当作已永久可信，而是重新执行：

- 发布 Schema 与 `artifact_hash` 校验。
- 项目、草稿和来源上下文一致性检查。
- 草稿完整重新物化与 `candidate_content_hash` 比对。
- 技能、装备、NPC 定义严格字段校验。
- 任务、对话、条件、奖励、路线、商店、配方与依赖循环检查。
- NPC 与对话一一对应检查。
- NPC `asset.*` 必须仍属于正式登记资产集合。
- campaign content 与 manifest 的独立校验和及交叉字段检查。

即使本地文件被篡改并重新计算 JSON 校验和，未登记 NPC 资产和非法内容结构仍会在 `inspect_campaign` 中被拒绝。这里的哈希用于完整性与一致性检查，不等同于远程身份签名。

## 运行时边界

`preview_campaign_import` 和 `install_campaign` 都返回：

- `activates_runtime:false`
- `requires_new_session:true`
- 独立 `save_namespace`

B-04 不会：

- 调用运行中 `ContentRegistry` 的替换接口。
- 把生成任务热注入当前战役。
- 修改当前角色、奖励、任务状态或声望。
- 读取或覆盖官方存档。
- 执行 Agent 生成的代码、表达式、场景、Shader 或文件路径。
