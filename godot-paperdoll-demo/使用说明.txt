原创像素素体与换装原型

运行：双击工作区根目录的 play-wardrobe-demo.cmd。
Godot 编辑：导入本目录 project.godot。

操作：
WASD / 方向键：移动。空格：挥剑。
P：暂停 / 恢复。暂停时 N：逐帧检查。
顶部切换上装、靴子、头发、武器；Cape / VFX 开关分别控制披风和剑光。
Anchors：显示各层裁切边框、地面原点和握点。
右上角支持 1x / 0.5x / 0.25x 播放。
左侧展示素体走路，中间展示同动作换装，右侧循环挥剑；底部为可操控角色。

资源结构：
assets/character.json：动作帧顺序、时长、层文件、offset、握点、武器角度和动作事件。
assets/frames/<图层>/<动作>/<帧>.png：每帧独立透明 PNG，紧裁切，尺寸可不同。
assets/weapons：每把武器只有一张图片，所有动作复用。尺寸不跟人物裁切框变化。
每帧 offset 相对于同一地面原点，重建位置 = 角色原点 + offset。
武器位置 = 角色原点 + hand；旋转围绕 weapon.grip，固定 scale=1。
剑光是独立的 effect 层，关闭不会影响人物、武器和动作时长。
行走 4 个姿势，每帧 0.20 秒；挥剑 6 个姿势，按蓄力 / 挥出 / 收势分别计时。

第一版装备：
骑士铠甲 / 斥候上装 / 无；骑士靴 / 斥候靴 / 无。
金发 / 铜发 / 无；蓝披风可选；钢剑 / 金剑 / 无。
同一套骨架坐标驱动全部服装，换装保持当前动作和帧数。
素体为成年女性比例的中性训练人偶，带固定训练服；近腿亮、远腿暗，便于检查交换。

制作方式与边界：
本版美术由原创程序像素绘制生成，没有使用 DNF 素材，也没有调用图像生成模型。
这是动作 / 图层 / 装备结构验证原型，不是最终姬骑士美术。
头发和披风目前跟随身体，没有额外摆动；暂无受击、死亡、上下方向和实战碰撞。
武器运行时旋转，固定长度，但低分辨率旋转的像素边缘可能跳变。
以后可将旋转结果预烘焙为武器帧，保留相同握点和长度，不需要重新生成角色。
新增服装需要覆盖同样的动作与帧，并使用相同 pose 坐标；新增武器只需单张图和 grip。
代码 generate-assets.gd 是当前制作模板，actor.gd 是分层播放器，demo.gd 是试玩界面。

重新生成：
工作区 godot.cmd --headless --path godot-paperdoll-demo --script res://generate-assets.gd
验证：
工作区 godot.cmd --headless --path godot-paperdoll-demo --script res://check.gd
