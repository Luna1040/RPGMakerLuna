# 游戏创作首页

双击根目录 `运行游戏.bat` 或 `运行游戏.cmd`。两者现在都进入首页，上方聊天创建游戏，下方横向游戏列表点击进入。`运行游戏-AI开发版.cmd` 作为旧开发快捷入口保留。

首次已有“晨钟城 · 姬骑士”。输入构想并发送会创建 `created-games/game-时间戳/` 独立 Godot 工程；Codex 会话按游戏隔离。正在生成的游戏不能启动，完成并通过导入检查后可点击进入。继续修改通过卡片“继续创作”；失败或中断也可从这里补充要求继续。

`created-games/catalog.json` 持久保存列表；重启仍可看到已创建项目。首页以真实目录为数据源，不把一张卡片当作已完成游戏。运行中的游戏通过 F1 面板“创作首页”返回。任务正在执行时先停止或等待完成再切换项目，避免跨工程修改。

启动仍依赖本机 Codex 已登录、Node 和 Godot。连接配置与会话记录在工作区 `.game-assistant`；不应公开提交。首页原型目前单任务串行，不支持多个游戏同时生成。

未完成的卡片显示 GODOT 占位区与“制作中 / 待继续创作”，禁用进入按钮。原始需求、最近需求、最近回复和工程路径随目录原子保存；Codex 会话按游戏保存。服务重启会把遗留的 creating 状态改成 paused，不会删除工程或自动重复提交生成。点击“继续创作”可带回原需求和上次回复，再发送接着做。

首页输入框自动保存未发送草稿及当前选择的游戏到 Godot user://creator-drafts.json。只关闭首页而后台还运行时，生成会继续；可以重新打开首页查看，不要求先停止。关闭整机后需再次启动并发送继续请求。恢复依赖本地工程、目录和 `.game-assistant` 会话文件保留；并非恢复被强制终止的命令执行现场。
