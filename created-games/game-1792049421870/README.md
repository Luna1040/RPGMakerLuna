# 真的在干了

第一人称办公桌摸鱼原型：在老板巡查之前完成拼豆和掌机跳跃关卡，再用文件夹遮住拼豆板，把掌机和镊子藏进抽屉。

## 打开和运行

需要 Godot 4.7.2 标准版。导入本目录的 `project.godot`，打开 `main.tscn` 后按 F5 运行。源码包包含运行素材，不含 Godot 引擎。

在 RPGMakerLuna 仓库中，也可通过原创作工具首页的《真的在干了》卡片进入。普通运行不需要团队服务或连接包；AI 开发助手仅在工具启动参数 `--ai-dev` 下启用。

## 操作

- 鼠标移动自然环顾，滚轮拉近/拉远。
- 左键查看物件；近看时右键按住旋转，右键短按松开放回拿起时的位置；Q可放回。
- 桌面右键拖动物件；绿色轮廓为合法落点，红色不可放；松手平滑落稳或返回。
- 左键开关抽屉。掌机、镊子进入抽屉落稳后关上才算藏好。
- 查看镊子后点“拿镊子拼豆”，查看板子后点“放一颗”或空格，共12颗。
- 查看掌机后点屏幕：A/D或方向键移动，空格跳跃，R重试，Esc退出。屏幕也提供鼠标操作。
- 老板预警后有17秒收拾；需要通过两次检查。

## 验证与范围

包含输入专项、完整玩法、几何和渲染清理测试。最新验证见 `VALIDATION.json`。三轴拖动覆盖30/60/120Hz，完整玩法通过真实移动/跳跃完成掌机关卡。自动检查不等于人工手感验收；封面为生成的宣传图，实际场景仍为原型。已知Mac Metal退出曾报告7个Texture RID警告。

运行自动检查：

```sh
godot --headless --editor --path . --quit
godot --headless --path . --script res://tests/desk_input_test.gd
godot --headless --path . --script res://tests/desk_flow_test.gd
```

源码包排除引擎缓存、导入生成缓存、私有连接信息、个人会话、生成原帧和模型权重；运行资产和字体已包含。
