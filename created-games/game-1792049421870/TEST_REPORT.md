# v9 发布验收

发布副本从用户已认可的最终r3源文件复制，核心运行脚本、运行素材和字体按SHA逐项一致。仅两个测试诊断输出路径改为user://，避免依赖未打包的art-jobs父目录。发布前从此副本导入并运行输入、真实三巡查完整流程、办公室/坐姿/路线/暂停、几何和60/30Hz/短卡顿固定子步测试；结果与文件SHA在VALIDATION.json。完整无缓存副本另验证首次导入脚本：第一阶段仅有已知字体初始化提示，字体缓存实际生成后，第二阶段原配置导入零错误；不将首轮提示计作完全零错误导入。

实际图面证据：Godot4.7.2、Apple M4、Metal Forward+隐藏视口完成r3桌面/同事/杯子/掌机转动/老板正常左上入镜检查。r2连续来返动作不受r3反光参数变化影响。掌机a/b真实像素变化证明重绘，未用静态贴图代替游戏。

实际音频证据：Dummy驱动的AudioEffectCapture，11片段、3独立总线、33分轨；12秒底噪loop wrap、键盘输出、靠近脚步约1.99倍RMS、检查静止停步、focus/Escape/mouse-exit排空尾音后总线为零，捕获无溢出。没有人工试听或扬声器测试。

界限：程序人物仍是原型，默认1280×800，不称16K CG品质。采集使用脚本推进时间，不证明人工手感或实玩FPS。Metal退出7个Texture RID、音频退出2个ObjectDB清理警告仍作为已知限制保留。包不含引擎、缓存、私有连接、捕获原WAV和生成原帧；来源摘要保留完整工作记录的追溯ID。
