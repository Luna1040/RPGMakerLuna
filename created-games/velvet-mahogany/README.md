# 绯夜 · 红木会所

默认进入六人德州扑克 NPC 牌桌，左侧可切换斗地主；「其他牌桌」可回到二十一点、百家乐和五张换牌扑克。入口仍为根目录「运行绯夜红木会所.cmd」，原 AI 开发版首页卡片也可启动。

## NPC 玩法 · 2026-10-15

- 德扑对手为陆沉（进攻型）、阿岚（稳健型）、老周（紧手型）、林薇（灵活型）、阿凯（松手型），各有独立筹码、动作提示和轮次。五位均显示人物头像；原有两位形象保留，新增三位的内置 image_gen 提示词见 art-jobs/npc-portraits-v2.txt。斗地主仍由陆沉与阿岚陪玩。德扑决策只用自己的底牌与公共牌；斗地主农民会配合队友。
- 德州扑克：六人无限注桌，每位初始1000筹码，10/20盲注，庄位轮转。可过牌、跟注、弃牌、加注和全下；四轮下注、七选五牌型比较、平局分池、边池和不足最小加注的全下规则。任一玩家破产后重开六人桌，不自动改成单挑。NPC底牌只在摊牌时亮出，弃牌不亮。公共牌发出时播放宽景荷官动作。
- 斗地主：一轮1–3分叫地主，最高分者取得3张底牌；无人叫分重新发牌。支持单、对、三张、三带一/二、顺子、连对、飞机及单/对翅、四带二/两对、炸弹、王炸。不连续带2和王；飞机单翅允许对子。两家不出后重置领牌。支持炸弹和春天翻倍，20分底分，地主对两农民零和计分。
- NPC牌桌筹码及积分属于当前会话；重开/关闭后重新开始。旧的单人玩法筹码存档保持独立。所有玩法均为本地虚拟筹码，无联网、支付或兑现。

三种本地单人玩法：二十一点（要牌、停牌、加倍，软17停牌，无分牌和保险）；百家乐（八副牌每局重洗，第三张补牌规则，庄胜5%佣金）；五张换牌扑克（Jacks or Better，点选留牌，更换一次）。返还倍率和规则显示在桌旁。初始2,000虚拟筹码，可补充。筹码、局数、胜局保存于user://salon-save.json。中途退出保留已扣下注。

美术由内置imagegen生成，最终素材assets/salon.png，提示词见art-prompt.txt。已检查生成图和游戏内显示。

## 动态荷官 v1 · 2026-10-15

运行素材位于 assets/dealer/{idle,deal,payout}.ogv，共约 5.6 MB。本机 H3 原始输出为 1024×576、24fps、124帧/动作、20步采样。保留完整赌场画面，因此未采用仅适用于黑底的抠图工具。待机采用正放/倒放衔接成约10.33秒循环；动作间0.2秒交叉淡化。

发牌释放点1.65秒，筹码释放点2.8秒。游戏逻辑独立决定牌和金额，视频仅作视觉表现。操作区遮挡视频下方的道具牌，正式牌面由Godot绘制。动作中禁用重复下注、补充筹码及切换玩法，结算入账后保存，动画结束恢复操作。

完整作业记录：art-jobs/dealer-motion-v1。含参考图、三个提示词、模板、每个作业的workflow/job/history/output-index、原MP4、372张源PNG和selection.json。源图不覆盖。manifest.json记录事件与处理策略。H3生成的人物细节存在轻微变化；未承诺视频里的装饰牌面、筹码数量与本局数值逐个对应。

新增验证：test_motion.gd 检查14项动作事件和重复操作防护，test_idle_loop.gd 验证完整待机循环。与 test_game.gd 的28项规则/鼠标测试共同使用。鼠标注入显式采用viewport本地坐标，避免Windows窗口缩放影响测试。所有测试应使用隔离APPDATA；不要对玩家正式存档执行测试。
