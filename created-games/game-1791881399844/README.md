# 星光采集 · 星湾弹幕远征

通过游戏大厅的「星光采集」进入。保留 GPT Image 原创背景、H3 动态飞船和门户，新增自动射击、三种敌机、局内武器成长和星蚀方舟 Boss。旧版永久成长存档兼容。

## 一局流程
出航后自动瞄准最近敌人射击。1 秒后敌机编队开始出现，随时间从侦察机的瞄准弹升级为重炮机扇形弹、晶核机旋转弹。30 / 75 / 120 秒获得战地补给，时间暂停，按 1–3 或点击选择武器，等级逐次提高到 4 级。可以换分支，等级保留。

150 秒出现星蚀方舟，清理之前的编队和弹幕。Boss 半血后增加瞄准扇形弹。击破后自动回收所有掉落，额外奖励 40 星砂、3 星核，5 秒后安全返航。完整战役约 3–4 分钟，受走位与武器选择影响。

- 星芒散射：多路扇形齐射，近距离火力强。
- 贯穿光矛：较慢的高伤害穿透弹，同一弹对每个敌人仅命中一次。
- 追踪僚机：主炮加两架僚机，自动弯曲追踪目标。
- 击破晶核机恢复 1 点船体、补充 1 次脉冲（最多 3），并掉落星核。

方向键移动；空格消耗 8 能源沿输入方向冲刺，方向固定且期间无敌；Q 消耗脉冲清除敌弹并伤害附近敌人，每航次初始 3 次。飞船中心白点是受击中心，机翼不判定敌弹。受伤后 1.6 秒保护。E/回车可在左侧空间站提前卸货；ESC 使用原菜单。

## 长期成长
四类永久升级：星砂精炼收益、能源上限、自动采集范围、速度与冲刺冷却，各 4 级。停靠时 1–4 升级，G 修复星门，TAB 切换已解锁星域。星门需要 36/64/92 星砂与 1/2/3 星核。

三个星域共享首版战役规则；紫晶风暴增加离子耗能云，日冕遗迹增加有预警的喷发带，高阶敌人和弹速更强。尚未制作三个独立 Boss 或三套独立关卡。

星砂和星核均不受容量限制，星砂精炼每级让单次采集收益 +1。失事保留一半随身星砂、遗失随身星核；仓库与永久成长保留。战地武器、脉冲、战斗时间每次出航重置。

安全返航、失事结算、购买和修复后自动保存至 `user://starlight_progress_v2.json`。离开时未入库航次不保存。原子替换存档，损坏数据不部分加载。

## 美术与来源
- 原有三张星域背景、飞船、空间站、星门、矿石：GPT Image 母图；H3 飞船尾焰、门户涡流与开启动画。
- 新增侦察机、重炮机、晶核机、星蚀方舟：内置 GPT Image 独立生成的透明 PNG，运行文件在 `assets/shooter-v1`，原图与提示词在 `art-source/*-original.png`、`art-source/shooter-prompts.json`。
- 新 Boss H3 循环 36 帧（8 fps）、击破 H3 效果 40 帧（20 fps，独立加法层，去灰底和边缘羽化）：生成记录、源视频、处理脚本放在 `art-source`；实际运行图集放在 `assets/h3-v1`。
- 发射、命中、爆炸、脉冲、升级、胜利六种音效为本项目程序合成，位于 `assets/shooter-v1/audio`。
- 所有弹道、命中、预警、发射时间均由代码控制，不从生成视频推测碰撞。常规敌机目前使用静态精细母图移动，未声称为视频动画。

## 验证入口
使用 Godot 4.7.2，先 `--headless --editor --path <本目录> --quit` 导入，再执行：
- `--headless --path <本目录> --script verify.gd`：36 项原有采集、成长、存档回归。
- `--headless --path <本目录> --script verify_combat.gd`：32 项战斗测试，含完整航次。完整流程测试开启测试专用无敌以验证流程，不代表真人难度评估。
- `--path <本目录> --script review_combat.gd`：实际渲染战斗、三选一和 Boss 截图，不改玩家存档。

项目为单机演示。音效已具备，暂无原创背景音乐。试玩难度仍可按人工体验调整。


## 肉鸽与性能更新
击杀敌机获得经验，升级时随机抽取三种不同舰装。12 种舰装分别强化射速、伤害、暴击、采集、装甲、脉冲、掉落、冲刺、多重弹、巨型弹、冰冻与连锁电弧，同类最多叠 3 层；可与三条武器路线组合。航次结束清空局内构筑，仓库与永久升级保留。星核不占货舱、不设采集数量上限。Boss 击破后清除敌弹、自动回收，5 秒后回到空间站，无需手动退出战斗。

敌我弹幕各使用一个 MultiMesh GPU 批次，敌弹上限 160，己方弹上限 200。移除背景贴图上重复绘制的 110 个星点；助手关闭时不再轮询重建隐藏文本框。低帧率时以小步追赶模拟时间，避免原先每帧最多推进 50 ms 导致慢放。右下角显示 FPS 和敌弹数。

本机压力对照（初始 160 发敌弹，正式 AI 助手参数）：旧版约 95 FPS / 887 次绘制，新版约 120 FPS / 171 次绘制，p95 帧间隔从 11.72 ms 降至 8.46 ms。未复现用户原窗口低于 10 FPS 的全部条件，因此保留可见指标供实机复核。`perf_combat.gd` 可复测；`verify_rogue.gd` 验证构筑与弹幕预算。常规战斗与存档测试仍适用。


### 刷怪与弹体进化
每波 6–10 架敌机，间隔由 2.2 秒逐步缩短至 1.1 秒，清空后 0.6 秒补充，同屏敌人严格不超过 28。敌弹 160、己方弹 200 的批量绘制预算继续生效。
每次局内升级都会增大弹体；巨型弹头额外增加 35% 宽度及 10% 伤害，分裂弹仓每层每轮额外发射 2 枚实弹，冰冻弹呈冰蓝色并使普通敌机减速，连锁电弧会击中 180 范围内另一名敌人。成长在航次结束重置。


### 四面包围
普通敌机与 Boss 从战斗区域四边进入，随机打乱四边顺序后轮流取用，避免长时间只出单边。出生点距离玩家至少 220，普通敌机向玩家接近并环绕，远程保持射击距离，图像随朝向旋转。不会跨屏瞬移。
28 架敌机 + 160 发敌弹压力测试：本机约 120 FPS，p95 8.57 ms，216 次绘制调用。测试脚本为 `perf_horde.gd`；`verify_surround.gd` 验证四边、角落安全距离与数量预算。随机舰装全部满级后，三选一转为维修、能源或星核补给，保证仍可继续战斗。
