# 星光采集 · 星路重连

通过游戏大厅的「星光采集」进入。场景使用原生矢量绘制，封面由 1280×800 实际画面生成，未使用 AI 位图或拉伸旧缩略图。

## 核心循环
探索星域、收集星砂与星核 → 回左侧空间站按 E 卸货 → 升级飞船或修复星门 → 探索更危险的星域。

四类永久升级：货舱容量、能源上限、自动采集范围、速度与冲刺冷却，各 4 级。三个星门分别需要 36/64/92 星砂及 1/2/3 星核。星门是长期目标，升级是可选的路线投资。收集每连续 5 次额外获得 1 星砂；连续 4.5 秒没拾取则中断。

静谧星湾适合起步；紫晶风暴增加危险物与离子耗能云；日冕遗迹有 3 秒预警后喷发的危险带。高阶星域的单颗星砂价值更高。

货满不妨碍收集星核。失事保留一半随身星砂、丢失随身星核，已入库物品、升级与星门不受影响。完成三座星门后仍可继续探索与升级。

## 操作
方向键移动，空格消耗 8 能源冲刺并避险，Q 扫描星核，E/回车出航或在空间站卸货。停靠时 1–4 升级、G 修复星门、TAB 切换已解锁星域；右侧按钮也支持鼠标。ESC 保留原有菜单与返回大厅。

## 存档与验证
安全返航、失事结算、升级和修复星门后自动保存至 user://starlight_progress_v2.json。离开时未入库的航次不会保存；不使用 R 清空成长。写入采用临时文件后重命名，损坏存档不部分套用。

`verify.gd` 验证输入、拾取、容量、结算幂等、成长、星域风险、存档和字体；`review.gd` 生成真实场景截图。当前版本为单机探索成长原型，没有多人或战斗敌人。
