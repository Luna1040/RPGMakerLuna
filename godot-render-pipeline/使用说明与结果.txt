同一原创角色：预渲染 PNG 与实时低分辨率 3D 对照

运行：工作区根目录 play-render-pipeline.cmd。
Godot 导入本目录 project.godot。

左侧：PNGActor 只加载磁盘 PNG，按每帧 offset 和 duration 播放，没有 3D 网格、相机或 SubViewport。
右侧：Model 通过独立 3D SubViewport 渲染，再通过 2D SubViewport 添加像素外描边。
两侧共用模型、材质、相机、姿势数据和脚底原点，因此停在相同关键帧时应得到相同外观。
开启 Live smooth 后，右侧在姿势间插值；左侧仍播放固定 PNG 帧，这时两侧不必相同。
预渲染本身不会提高美术品质；它把渲染成本移到制作阶段，并允许后续逐帧像素修整。

操作：
顶部 BODY 切换明确成年的女性 / 男性体型。
OUTFIT：Neutral base 无衣基础形体、Knight 铠甲、Scout 上装、Low-neck dress 礼服、Swimwear 泳装。
女性泳装为连体式，男性泳装为泳裤，上身保持赤膊。
HAIR：金发马尾、铜发马尾、短发、无发；VIEW：18 / 55 / 90 度正交相机。
WEAPON：钢剑 / 金剑 / 无；VFX 独立开关。
Walk / Attack / Idle 切换动作。P 暂停，N 逐帧，F 镜像，空格攻击，W 走路。
速度菜单支持 1x / 0.5x / 0.25x。
Re-bake 重做当前装扮的 PNG 组，保留其他装扮组。
2D base 按钮展示新生成的无固定内衣 AI 基础人物九宫格。

基础形体修改：
身体是中性、无私密部位细节的成年游戏人偶，没有固定内衣或训练服。
女性基础形体保留胸部轮廓、腰臀曲线；男性保留胸廓和简化腹部肌肉体积。
没有乳头、乳晕、生殖器或其他私密部位建模。相应区域为平滑统一肤色。
裙装、泳装、铠甲独立于基础形体；不依赖把内衣覆盖掉。
动作使用固定骨长双关节 IK；武器为同一网格，只移动 / 旋转。
新 AI 2D 基础人物已保存为 assets/ai-body-reference-v2.png，前一个实验的 ai_actor.gd 也改为使用 ai-skin-v2.png。
AI 2D 服装 / 发型配对失败没有被隐藏，它仍保留在前一个实验里作为对照。

像素风处理与边界：
每部件使用固定光方向的三档明暗材质；关闭抗锯齿，添加一逻辑像素外描边，整数 4 倍放大。
两侧人物约 61 逻辑像素高；目标纹理 128×128 为剑和特效保留空白。
这些处理改善轮廓读法，不会自动达到手工精美像素画的品质。
模型仍是程序几何原型；脸、头发、盔甲细节、动画节奏和布料形态仍需要美术制作。
当前礼服为简单贴身上衣和裙摆；没有裙摆物理或完整衣物穿模处理。
没有标准 Skeleton3D 蒙皮资产，暂无实战碰撞、受击、死亡、多方向完整动作。

PNG 资源：
exports/sets/pixel_v3/<体型_服装_发型_武器_视角_特效>/frames.json
同目录 idle/、walk/、slash/ 中有 1 + 4 + 6 张独立透明 PNG。
每张图片紧裁切，尺寸可不同；JSON 保存相对脚底原点的 offset 和停留时间。
第一次选择新装扮，在隐藏的制作视口中烘焙一次；制作视口随后销毁。再次选择直接加载缓存 PNG。
这是开发预览缓存流程；正式发布的纯 PNG 游戏应提前烘焙所需装扮，去掉实时制作视口及 3D 资源。
这些 PNG 是完整装扮合成快照，包含开启的武器和特效。运行时 3D 装备仍独立。
正式离线自由换装还需装备层导出和深度遮挡处理，或按装扮组合烘焙并管理缓存。
如修改模型 / 着色器，须 Re-bake 或更换缓存版本，避免旧 PNG 与新模型混用。

验证结果：
六组装扮：女性铠甲、女性基础体、女性泳装、女性礼服、男性基础体、男性泳装。
每组 11 帧，共 66 帧，实际 GPU 渲染后与磁盘 PNG 重建的完整 128×128 图像逐字节一致。
验证帧内容未越出画布、紧裁切尺寸和偏移正确、腿骨长度固定、武器缩放固定。
验证 PNGActor 没有任何子节点，且基础形体没有固定内衣部件。
verification.json 保存六组清单和结果；check.gd 可重跑验证。
预览截图在 preview/dress00000003.png 和 preview/male00000003.png。

生成方式：
3D 模型、材质、装备和动作由原创代码制作，不是 AI 生成的现成 3D 成品。
只有 2D 基础人物修改使用内置 imagegen；真实提示词保存在 GENERATION-PROMPTS.txt。

本次结论：
预渲染与实时渲染是运行方式选择，不是两种不同的美术品质。
要达到精美像素风，更值得继续评估：3D 控制动作和遮挡，离线输出后按选定美术风格进行像素修整。
AI 独立画衣服 / 发型再拼接，本次仍不能可靠直接配对，不建议继续扩大量产。
