# 平台工程与生产流程

一套标准 Godot 工程体系，连接自然语言创作、Codex 开发、经 FRP 调用高性能显卡主机做美术，以及游戏内持续迭代。小游戏快速产出，精品项目持续精修，作品与素材随开发不断积累。

## 开放底座，专业接力

平台采用开放开源的 Godot。场景、脚本、资源与项目配置保留标准工程结构，开发者可以直接用 Godot 编辑器接手。AI 搭基础、人工做精修、人机共同扩展，都在同一套工程中完成。熟悉 Godot 的团队可直接复用已有开发经验。

## 生产节奏与作品积累

| 项目 | 团队经验与规划 |
| --- | --- |
| 日常小游戏 | 团队使用经验：每天约两款 |
| 精品项目 | 团队使用经验：一天搭起基础内容，随后持续完善章节、玩法与美术 |
| 当前作品矩阵 | 六款可试玩工程，覆盖收集、挖掘、经营、扑克、动作 RPG 与三维武侠 |
| 单账号月度产能估算 | $200 订阅支持 100 个小游戏与 50 个精品游戏开发项目；精品项目包含基础开发与后续迭代 |

每个游戏拥有独立工程与会话。大厅统一展示作品，项目目录持续保存代码、素材与开发成果；独立开发会话与执行环境承接各项目工作。当前大厅桥接器逐项执行任务，完成或停止当前任务后切换目标；协作会话按工程和文件分工。

## 订阅开发，FRP 调用显卡主机

| 环节 | 生产方式 | 成本构成 |
| --- | --- | --- |
| AI 开发 | Codex 使用已有 ChatGPT 登录与订阅额度 | 团队采用 $200 / 账号 / 月方案，额外额度按实际使用计费 |
| 图片生成 | 高性能显卡主机上的 ComfyUI + Flux，创作端经 FRP 提交 | 按张生成服务费为 0 |
| 视频生成 | 高性能显卡主机上的 ComfyUI + H3，创作端经 FRP 提交 | 按秒生成服务费为 0 |
| 资产积累 | 图片、视频、动作帧与工程回到创作端保存 | 可持续复用、修改与接入 |

150 个开发项目分摊，订阅成本为 **$200 ÷ 150 ≈ $1.33 / 项目**。

订阅额度和刷新时间以账户显示为准。订阅与 API 计费方式见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/pricing)。

**相比 API 编程＋云端生图，成本降低超过 75%。**

## 游戏现场直达开发上下文

| 上下文 | 接入方式 |
| --- | --- |
| 当前场景与引擎版本 | 助手面板读取运行信息 |
| 游戏画面 | 打开面板时捕获截图 |
| 区域与角色坐标 | 已接入场景状态接口的游戏提供位置数据 |
| 目标工程与原始需求 | 桥接器补充项目目录和任务信息 |
| 代码、素材与美术工具链 | 提供工具链信息，并按任务读取当前工程文件 |

玩家在现场提出需求，Codex 结合工程和画面定位问题，修改后通过检查、重启和试玩继续完善。后续剧情、角色、动作与玩法沿用这条开发链路。

## 美术生产与素材来源

图片和视频不在创作电脑上现算。创作端通过 FRP 连接高性能显卡主机，ComfyUI 在主机上跑 Flux 与 H3。生成结果回到工程，再做选帧、抠图、图集和运行时接入。

现有作品同时展示多种素材接入路径：经 FRP 在高性能显卡主机上由 ComfyUI 生成、部分红木会所图片的内置 imagegen 生成，以及武侠原型的客户端素材复用。具体来源随各项目作业记录保存。

完整作品、操作入口与验证命令见 [平台 README](../README.md)。
