# 平台技术与数据说明

README 中的能力名称是既有模块与流程的宣传命名，不表示另行研发了基础模型或游戏引擎。

## 产出节奏

“每天两个小游戏”和“一天搭起精品基础”来自团队提供的实际使用经验，不是统一工作负载下的实验室基准。前者针对轻量游戏，后者指精品项目基础内容；后续章节与精修持续迭代。任务范围、素材量、服务状态与硬件影响实际耗时。

## 本地生成费用

已有硬件、模型与运行环境下，本地 ComfyUI 图片和视频推理没有按张、按秒的付费生成 API 费用。硬件购置、人工、电费另计；Codex 编程助手使用用户自己的登录和服务额度。历史素材来源以作业记录为准，部分红木会所图片使用内置 imagegen，武侠原型包含客户端素材复用。

## 调度与项目隔离

每个游戏使用独立工程与会话。当前大厅桥接器使用单任务保护，任务进行中需先完成或停止再切换目标。多个独立开发会话与执行环境可以分别开展项目工作，但本仓库没有实现无限并发调度或云端集群。不要让多个会话同时修改相同文件。

## 现场上下文

助手附带当前场景路径、引擎版本和打开面板时的截图；接入对应状态接口的场景还提供区域与角色坐标。目标目录、原始需求和美术工具链信息由桥接器补充。素材与代码在当前工程中按需读取，并非所有对象的坐标及全部素材都随每个请求自动上传。

## 宣传主张与实测数据

“遥遥领先”和竞品相关团队宣言属于团队宣传立场。本项目没有提供同条件竞品基准数据，不将这些宣言当作量化测试结论，也没有声称已测得“领先同行 15%”。六款作品、代码和验证入口用于检查实际实现。
