苍石庭院 · 网页试玩包（2026-10-09）

入口：index.html。游戏运行文件为 game.html / game.js / game.wasm / game.pck 等，请保持同目录。

分发方式
1. 将 ZIP 内全部文件解压上传到一个静态网站目录，通过 HTTPS 链接分发。
2. 或上传 ZIP 到支持 HTML5 游戏的平台，入口设置为 index.html。
3. 本地检查：安装 Python 后，在此目录运行 python -m http.server 8793，再打开 http://localhost:8793/。
不要双击 HTML 使用 file:// 运行；浏览器需要通过 HTTP/HTTPS 加载 WebAssembly 和游戏资源。
本包使用单线程 Web 导出，不依赖跨源隔离响应头。服务器须正确提供 .wasm（application/wasm）、.js 和 .pck 文件。
建议启用服务器 gzip/Brotli 压缩并避免重命名 game.* 文件。

操作
WASD/方向：移动；0.5秒内双击方向并按住：奔跑；空格：跳跃。
J：普攻三连；奔跑时J：冲刺斩；空中J：下劈。1/2/3：技能；K：雷光。
E：交互/拾取；Q：附近装备拾取穿戴；I：背包属性；M：地图；R：复位。
点击游戏画面获得键盘焦点。浏览器存储被禁用时，装备可能无法跨刷新保存。

当前范围
桌面键盘试玩；尚无手机触控、敌人副本、完整任务流程。
装备改变属性，暂不改变角色外观。装备存于本浏览器；箱子/宝箱/杂物为本次场景状态。
世界地图使用地图工坊的离线快照，不依赖 8791 服务。
网页端默认隐藏开发面板。无后台服务器、登录或数据收集。

Noto Sans SC 字体采用 SIL OFL，使用游戏所需字符子集，许可证见 FONT-LICENSE.txt。
