# 游戏制作 skill 分享包

把压缩包中的 `game-production` 文件夹放到 `~/.codex/skills/`，重新打开会话，输入：

> 使用 $game-production，帮我们制作一个新的游戏原型，先确认美术与机制的小样，再批量生产。

包括角色母图和动作生产、透明帧与取帧工具、Godot 机制/地图/网状任务、真实踩坑和验证发布流程。团队 API 操作见 skill 内 `references/team-api.md`。

公开包不含模型、游戏源素材、服务器地址或密钥。维护者另行私发连接包；不要把私有连接包上传仓库。成员启动 frpc 访问端后使用 `http://127.0.0.1:19316`，不是访问维护者的 localhost。

本轮验证：skill 结构校验通过；4 项选帧边界测试通过；BiRefNet 抠图脚本在一张源帧完成运行并检查深浅底；STCP 经远端服务器的上传→排队→执行→历史→下载回路通过。回路使用合成测试图和 LoadImage/SaveImage；没有重复运行昂贵的 H3 完整视频生成。H3 参数来自已有成功制作记录，并检查当前服务节点和模型选项。

服务按可信团队共用队列设计，无每用户隔离和配额。当前隧道从主机自己的 visitor 回连验证，成员异地连接仍应首次运行 check 确认。
